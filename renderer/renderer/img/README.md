# img/

Coloca aquí el logo del proyecto como `logo.svg` (o `logo.png`).

Se usa automáticamente en tres lugares:
- Pantalla de inicio (grande)
- Modal "Acerca de / Referencias" (mediano)
- Pestaña de Ayuda (pequeño, junto al título)

Si el archivo no existe, esos espacios simplemente no muestran nada — no rompe la app.
Tamaño recomendado: SVG vectorial, o PNG de al menos 200x200px con fondo transparente.
